# Singly Linked List in C

A menu-driven implementation of a singly
linked list using C.

## Features
- Insert at beginning
- Insert at end
- Delete from beginning
- Delete from end
- Display linked list

## Concepts
- Structures
- Pointers
- Dynamic memory allocation
- malloc() and free()
- Linked list traversal

## How to Run

Compile:
gcc linkedlist.c -o linkedlist

Run on Windows:
.\linkedlist.exe

## Language
C
